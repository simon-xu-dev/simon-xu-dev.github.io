📈 Highlighted Open Source Projects

CIMS 2024

Product quality prediction model based on generative adversarial network and hard case mining

Jianfeng Li, Xue Bai, Weifeng Xu

This project tackles low recall in defective product detection from imbalanced process data. It combines F-score/mRMR feature selection, WGAN-based augmentation, and a LightGBM model with focal loss and threshold adjustment. Validated on the SECOM dataset, it significantly improves recall while maintaining overall accuracy.

📄 Paper 🌐 Project Page 💻 Code
IEEE Access 2020

Automatic Sleep Stage Classification With Single Channel EEG Signal Based on Two-Layer Stacked Ensemble Model

Weifeng Xu

This project develops an automatic sleep staging system using single‑channel EEG signals for convenient, non‑invasive monitoring. It proposes a two‑layer stacked ensemble model (RF + LightGBM) with a class balance strategy to significantly improve the recognition rate of the N1 stage, which is typically difficult to detect. Validated on Sleep‑EDF and Sleep‑EDF Expanded databases, the model achieves competitive overall accuracy and robust performance across subjects.
